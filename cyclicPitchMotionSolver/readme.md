## 1. Definition of Rotor Pitch Motion

In helicopter aerodynamics, rotor control is achieved through two primary mechanisms: **collective** and **cyclic** pitch. These adjustments allow the aircraft to transition between vertical and directional flight.

### Collective Pitch

**Collective pitch** refers to the simultaneous and equal change in the pitch angle of all rotor blades. By adjusting the collective, the pilot changes the total lift generated by the entire rotor disk, allowing the helicopter to climb or descend.

### Cyclic Pitch

**Cyclic pitch** involves varying the pitch angle of each blade individually based on its position in the rotation, known as the **azimuth angle** ($\psi$). This variation creates an imbalance of lift across the rotor disk, causing it to tilt. This tilt redirects the thrust vector, enabling horizontal movement (forward, aft, or lateral).

### Mathematical Formulation

The pitch angle for each blade is formulated with respect to the azimuth angle ($\psi$) as follows:
$$\theta(\psi) = \theta_0 - \theta_{1c} \cos(\psi) - \theta_{1s} \sin(\psi)$$

* **$\theta_0$**: Collective pitch

* **$\theta_{1c}$**: Lateral cyclic pitch

* **$\theta_{1s}$**: Longitudinal cyclic pitch


## 2. `cyclicPitchMotion` Solver Implementation

To simulate the cyclic pitch motion of rotor blades, the **`cyclicPitchMotion`** solver was implemented based on the `oscillatingRotatingMotion` class provided by OpenFOAM. The solver uses a harmonic oscillation function to represent pitch changes over simulation time ($t$).

### Solver Parameter Mapping

The solver calculates the amplitude ($A$) and phase angle ($\phi$) based on the lateral and longitudinal cyclic pitch requirements. These values are then applied to the OpenFOAM solver as follows:

### Table 1. `cyclicPitchMotion` Parameter Comparison

| Feature | `oscillatingRotatingMotion` (Base) | `cyclicPitchMotion` (Custom) |
| :--- | :--- | :--- |
| **Governing Equation** | $\theta(t) = A \sin(\omega t)$ | $\theta(t) = \theta_{0} + A \sin(\omega t + \phi)$ |
| **Pitch Angle ($\theta$)** | Current pitch angle | Current pitch angle |
| **Offset ($\theta_{0}$)** | N/A | **Collective Pitch ($\alpha_{0}$)** |
| **Amplitude ($A$)** | Amplitude angle vector | **Cyclic Amplitude angle** |
| **Velocity ($\omega$)** | Radial velocity | Radial velocity |
| **Time ($t$)** | Simulation time | Simulation time |
| **Phase ($\phi$)** | N/A | **Phase angle** |

The conversion from physical pitch requirements to solver parameters is defined by the following equations:
$$\theta(t) = \theta_0 + A \sin(\omega t + \phi)$$

$$A = \sqrt{\theta_{1c}^2 + \theta_{1s}^2}$$

$$\phi = atan2(-\theta_{1s}, -\theta_{1c})$$

### Source Code Logic

The solver's core logic is located in the `transformation()` function within `cyclicPitchMotion.C`, which calculates the `septernion` for mesh motion:
```
vector eulerAngles = normalizedAxis * (alpha0_ + amplitude_*sin(omega_*t + phase_));
eulerAngles *= degToRad();
quaternion R(quaternion::XYZ, eulerAngles);
septernion TR(septernion(-origin_)*R*septernion(origin_));
```

## 3. Installation Instructions (OpenFOAM-v2512)

Follow these steps to add the `cyclicPitchMotion` solver class to your OpenFOAM installation.

### Step 1: Create Directory and Copy Source Files

Create the source directory within the `meshTools` library and copy the header (`.H`) and source (`.C`) files.
```
mkdir -p $FOAM_SRC/meshTools/solidBodyMotionFunctions/cyclicPitchMotion
cp cyclicPitchMotion.* $FOAM_SRC/meshTools/solidBodyMotionFunctions/cyclicPitchMotion
```

### Step 2: Register the New Class

Add the new source file to the `Make/files` list of the `meshTools` library so the compiler includes it.
```
vi $FOAM_SRC/meshTools/Make/files
```
Inside the file, add the following line in the `solidBodyMotion` section:
```
...
$(solidBodyMotion)/cyclicPitchMotion/cyclicPitchMotion.C
...
```

### Step 3: Recompile OpenFOAM

Navigate to the OpenFOAM project directory and compile the modified library using `Allwmake`.
```
cd $WM_PROJECT_DIR
./Allwmake -j
```

### 4. Usage in `dynamicMeshDict`
To apply the solver to your simulation, define the cyclicPitchMotion function within the constant/dynamicMeshDict file.Configuration ExampleThe following entry defines a cyclic pitch motion centered at the origin (0, 0, 0). Based on the provided equations, the blade pitch will oscillate between a maximum angle of $(\theta_0 + A)$ and a minimum angle of $(\theta_0 - A)$.

```
dynamicFvMesh   dynamicSolidBodyMotionFvMesh;

solidBodyMotionFunctions
{
    blade1
    {
        solidBodyMotionFunction cyclicPitchMotion;
        origin      (0 0 0);      // The center of rotation (Rotor Hub)
        axis        (0 1 0);      // Pitch axis (typically the longitudinal axis of the blade)
        alpha0      8.0;          // Collective Pitch (theta_0) in degrees
        amplitude   2.5;          // Cyclic Amplitude (A) in degrees
        omega       104.7;        // Radial velocity (w) in rad/s
        phase       1.57;         // Phase angle (phi) in radians
    }
}
```

Parameter Breakdown
- `origin (0 0 0)`: Sets the focal point of the motion. All pitch rotations occur around this coordinate, which typically represents the rotor hub or the blade's pitch hinge.
- `alpha0 8.0`: This is the base collective pitch ($\theta_0$).
- `amplitude 2.5`: This is the calculated cyclic amplitude ($A$).
- `Motion Range`: In this specific setup, the blade will undergo a cyclic oscillation ranging from a minimum of 5.5° ($8.0 - 2.5$) to a maximum of 10.5° ($8.0 + 2.5$) as it rotates through its 360° azimuth.
- `omega`: Corresponds to the rotor's rotational speed. For example, `104 rad/s` equates to approximately `1000 RPM`.
- `phase`: Determines the orientation of the tilt (e.g., whether the maximum pitch occurs at the 12 o'clock or 3 o'clock position).
