# Repository for CFD knowledge

- **OpenFOAM_on_Ubuntu**: install guide for OpenFOAM-v2512 on Ubuntu Linux

- **cyclicPitchMotionSolver**: adding cyclicPitchMotion solver for simulating the rotor cyclic pitch motion

- **multiMotionSolver**: dynamicMeshDict configuration for nesting sliding mesh

- **oscillating_airfoil2D**: cyclicPitchMotion example case using pimpleFoam solver
  
- **salomeToOpenFOAM**: export salome mesh with cellZones to OpenFOAM
